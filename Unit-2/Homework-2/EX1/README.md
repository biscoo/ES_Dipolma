# Matrix 2x2 Summation
 
A simple C program that reads two 2x2 matrices from the user, adds them
together, and prints the result.
 
## What it does
 
- Asks you to enter the 4 elements of Matrix 1
- Asks you to enter the 4 elements of Matrix 2
- Adds the two matrices element by element
- Prints the resulting 2x2 matrix
The matrices use `float`, so decimal values work too.
 
## Example
 
```
Matrix 2x2 Summation
###################
Enter the elements of Matrix 1
Enter a11: 1
Enter a12: 2
Enter a21: 3
Enter a22: 4
Enter the elements of Matrix 2
Enter a11: 5
Enter a12: 6
Enter a21: 7
Enter a22: 8
The Sum of the 2 matrices:
6.00    8.00
10.00   12.00
```
 
## Notes
 
- Input labels follow the aij convention (a11, a12, a21, a22).
- Everything is in a single file.
