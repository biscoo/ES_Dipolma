# Average Calculator
 
A simple C program that reads a set of numbers from the user and calculates
their average.
 
## What it does
 
- Asks how many numbers you want to enter
- Read values
- Adds them up and prints the average (to 3 decimal places)
The values are stored in a `float` array, so decimal numbers work too.
 
## Example
 
```
Average Calculator
###################
Enter the number of data: 4
Enter number 1: 10
Enter number 2: 20
Enter number 3: 30
Enter number 4: 40
The average value of data is: 25.000
```
 
## Notes
 
- Everything is in a single file.
- The count of numbers is entered first, then each value one by one.
