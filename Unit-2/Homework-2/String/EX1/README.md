# Character Frequency Counter

A simple C program that counts how many times a given character appears in a
string entered by the user.

## What it does

- Reads a line of text from the user
- Asks for a single character to look for
- Scans the string and counts how many times that character appears
- Prints the frequency

## Example

```
String Char Frequency Search (Linear)
#####################################
Enter a String: programming
Enter a char to be found: g
Frequency of the char g: 2
```

## Notes

- The search is case-sensitive ('a' and 'A' are counted separately).
- The text can contain spaces.
- Everything is in a single file.
