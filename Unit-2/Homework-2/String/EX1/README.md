# String Analyzer

A simple C program that takes a string and reports three things about it:
how often a chosen character appears, the string's length, and the string
reversed.

## What it does

- Reads a line of text from the user
- Asks for a single character to look for
- In one pass it calculates:
  - the frequency of that character
  - the length of the string
  - the reversed string
- Prints all three results

## Example

```
String Char Frequency Search (Linear)
#####################################
Enter a String: programming
Enter a char to be found: g
Frequency of the char g: 2
The string length: 11
The reverse of the string: gnimmargorp
```

## Notes

- The character search is case-sensitive ('a' and 'A' are counted separately).
- The text can contain spaces.
- Everything is in a single file.
