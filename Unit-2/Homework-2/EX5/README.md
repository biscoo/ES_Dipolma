# Array Search (Linear)

A simple C program that searches an array for a value using linear search
and reports the position where it is found.

## What it does

- Asks for the array size and reads the elements
- Prints the array back
- Asks for a value to search for
- Scans the array element by element (linear search)
- Prints the location if found, or a "not found" message

The array size comes from your input at runtime (using a variable-length
array).

## Example (found)

```
Array Search (Linear)
###############
Enter the array size: 5
Enter the elements of the Array
Element 1:10
Element 2:20
Element 3:30
Element 4:40
Element 5:50
10 20 30 40 50
Enter the element to be searched:
30
Number found at location 3
```

## Example (not found)

```
Enter the element to be searched:
99
Number not found....
```

## Notes

- Positions are 1-based (1 = first element).
- If the value appears more than once, every location is printed.
- Everything is in a single file.
