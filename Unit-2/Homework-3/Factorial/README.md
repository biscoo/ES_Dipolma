# Factorial Calculator

A simple C program that calculates the factorial of a positive integer using
recursion.

## What it does

- Asks the user for a positive integer
- Computes its factorial using a recursive function
- Prints the result

The factorial of n (written n!) is the product of all integers from 1 to n,
for example 5! = 5 x 4 x 3 x 2 x 1 = 120. By definition, 0! = 1.

## Example

```
Please enter positive integer:
5
The Factorial of 5 is: 120
```

## Notes

- Uses recursion: factorial(n) = n * factorial(n - 1), with factorial(0) = 1.
- Results are stored in an int, which can hold factorials up to 12!.
- Everything is in a single file.
