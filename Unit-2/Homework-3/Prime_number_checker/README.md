# Prime Numbers in an Interval
 
A simple C program that reads two numbers defining an interval and prints all
the prime numbers found within it.
 
## What it does
 
- Asks the user for two numbers (the interval bounds)
- Checks each number in the interval for primality
- Collects the primes into an array
- Prints all the prime numbers found
A number is tested for primality by trying to divide it by every value from 2
up to its square root — if none divides it evenly, it's prime.
 
## Example
 
```
Please enter 2 numbers (Interval):
1 10
The prime numbers between 1 and 10: 2	3	5	7
```
 
## Notes
 
- Enter the two interval numbers separated by a space.
- Numbers below 2 are skipped (0 and 1 are not prime).
- Everything is in a single file.
