# EX4: Store Information of Students Using Structure

## Description
An array of 10 `SStudent` structures is created. The roll number is assigned automatically (1 to 10), and the user enters the name and marks for each student. All the data is then displayed.

## Concepts
- Array of structures
- Looping over structure elements with `students[i].member`
- `#define` for the array size (`NUM_OF_STUDENTS`)

## Sample Output
```
Enter information of students:

For roll number 1
Enter name: Beshoy
Enter marks: 98

For roll number 2
Enter name: Hani
Enter marks: 89
.
.
.
Displaying information of students:

Information for roll number 1:
Name: Beshoy
Marks: 98
.
.
.
```
