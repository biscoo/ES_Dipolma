# EX1: Store Information of a Student Using Structure

## Description
A structure `SStudent` holds a student's `name`, `roll` and `marks`. One structure variable is filled with data entered by the user, then the data is displayed.

## Concepts
- Defining a `struct` and declaring a structure variable
- Accessing members with the `.` operator
- Reading strings, integers and floats with `scanf`

## Sample Output
```
Enter information of students:

Enter name: Beshoy
Enter roll number: 25
Enter marks: 330.20

Displaying Information
Name: Beshoy
Roll: 25
Marks: 330.20
```
