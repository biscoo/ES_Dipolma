# EX3: Add Two Complex Numbers by Passing Structure to a Function

## Description
A structure `SComplex` holds the `real` and `imag` parts. Two complex numbers are read, passed **by value** to `Add_Complex()`, and the function returns a new structure with the sum.

## Concepts
- Passing structures to functions (by value)
- Returning a structure from a function

## Sample Output
```
For 1st complex number
Enter real and imaginary respectively: 2.3
4.5

For 2nd complex number
Enter real and imaginary respectively: 3.4
5
Sum=5.7+9.5i
```
