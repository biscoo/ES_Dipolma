# Unit-2 Assignment 1

A small C program with a menu. You type a number and it runs one of the exercises,
then goes back to the menu. Type 8 to quit.

## Exercises

1. Prints "C Programming" between two lines of #.
2. Reads an integer and prints it back.
3. Reads two integers and prints their sum.
4. Reads two numbers and prints their product.
5. Reads a character and prints its ASCII value.
6. Reads two integers and swaps them (without a temp variable).

## How to build and run

I wrote and built this in Eclipse (CDT) with the MinGW GCC toolchain on Windows.
Open the project, then Project > Build Project, and run it.

To build from the command line instead:

    gcc main.c -o Unit-2

Then run Unit-2 (or Unit-2.exe on Windows).

## Notes

- Everything is in one file, main.c.
- Enter the number for the exercise you want at the menu.
